# Project Charter (Draft)

| Item | Description |
|---|---|
| Project | Procurement Process Improvement |
| Sponsor | To be confirmed |
| Business owner | Procurement Manager (assumption) |
| Analyst | Junior Business Analyst (portfolio role-play) |
| Problem | Fragmented request intake and approval tracking |
| Objective | Standardize intake and improve process visibility and traceability |
| Delivery approach | Discovery → requirements → process design → prototype → UAT |
| Constraints | Fictional case; no real ERP integration; no real approval execution |

## Success measures to baseline
- First-pass request completeness
- Median request-to-approval cycle time
- Number of clarification loops per request
- Number and age of pending approvals
- Percentage of requests with complete audit history

Targets must be agreed after baseline measurement; this project does not invent numerical targets.
